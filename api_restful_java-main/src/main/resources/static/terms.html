Termos de Serviço

Music Catalog API · Última atualização: 2 de novembro de 2026

Resumo: a API é pública e gratuita, não tem login e guarda os dados só em memória. Qualquer pessoa pode ver e alterar o que for cadastrado, e tudo é apagado quando o servidor reinicia. Não cadastre dados pessoais nem use a API para guardar algo importante.

1. Sobre a API

A Music Catalog API é uma API RESTful para cadastrar e consultar um catálogo de discos: artistas, álbuns, faixas, capas, gêneros e gravadoras. Ela é desenvolvida e mantida por alunos do curso de TSI do Senac São Paulo. Ao fazer qualquer requisição à API, inclusive pela documentação em /swagger-ui.html, você concorda com estes termos.

2. Uso permitido

Você pode usar a API para estudar, testar e integrar com as suas aplicações. Não é permitido:

  • enviar um volume de requisições que prejudique o serviço para os demais usuários (por exemplo, testes de carga ou scripts em laço);
  • tentar explorar falhas, acessar o servidor por outros meios ou contornar as regras da API;
  • cadastrar conteúdo ilegal, ofensivo ou que viole direitos de terceiros;
  • cadastrar dados pessoais de qualquer pessoa (CPF, telefone, endereço, e-mail etc.).

3. Dados cadastrados

  • São públicos. A API não tem autenticação: tudo o que for cadastrado pode ser lido, alterado ou excluído por qualquer pessoa que use a API.
  • São temporários. Os dados ficam num banco em memória e são apagados sempre que o servidor reinicia. Não existe backup.
  • Imagens não são hospedadas. O campo imageUrl das capas guarda só o endereço da imagem. Use apenas links de imagens que você tem direito de divulgar.

4. Disponibilidade

A API é oferecida sem garantia de disponibilidade. Ela pode ficar fora do ar ou demorar para responder.

A versão faz parte da URL (ex.: /v1/artists). Mudanças que quebram a compatibilidade saem numa versão nova (/v2), e a anterior continua no ar. Cada versão tem a sua documentação no Swagger.

5. Isenção de garantias e de responsabilidade

A API e o seu código são fornecidos “no estado em que se encontram”, sem garantias de qualquer tipo. Os mantenedores não se responsabilizam por perdas ou danos causados pelo uso da API ou pela falta dela.
