Termos de Serviço

Music Catalog API · Última atualização: 2 de novembro de 2026

Resumo: a API é gratuita e a leitura é livre. Para criar, alterar ou excluir dados é preciso uma chave de API, que qualquer pessoa gera informando nome e e-mail. Os dados ficam só em memória e são apagados quando o servidor reinicia. Não cadastre dados pessoais no catálogo nem use a API para guardar algo importante.

1. Sobre a API

A Music Catalog API é uma API RESTful para cadastrar e consultar um catálogo de discos: artistas, álbuns, faixas, capas, gêneros e gravadoras. Ela é desenvolvida e mantida pela Giovanna de Lima, aluna do curso de Tecnologia em Sistemas para Internet do Senac São Paulo. Ao fazer qualquer requisição à API, inclusive pela documentação em /swagger-ui.html, você concorda com estes termos.

2. Uso permitido

Você pode usar a API para estudar, testar e integrar com as suas aplicações. Não é permitido:

  • enviar um volume de requisições que prejudique o serviço para os demais usuários (por exemplo, testes de carga ou scripts em laço);
  • tentar explorar falhas, acessar o servidor por outros meios ou contornar as regras da API, como o limite de requisições;
  • cadastrar conteúdo ilegal, ofensivo ou que viole direitos de terceiros;
  • cadastrar dados pessoais de qualquer pessoa no catálogo (CPF, telefone, endereço, e-mail etc.).

Cada cliente pode fazer até 60 requisições por minuto sem chave de API e 120 com chave. Acima disso a API responde 429 Too Many Requests, e o cabeçalho Retry-After informa em quantos segundos tentar de novo.

3. Chaves de API

  • Para que servem. Ler o catálogo é livre. Criar, alterar e excluir exige uma chave no cabeçalho X-API-Key, gerada em POST /api-keys.
  • O que é guardado. Para gerar a chave pedimos nome e e-mail, usados só para identificar quem é dono dela. A chave em si não é guardada, só uma impressão digital dela (hash), por isso ela aparece uma única vez, na criação.
  • Sua responsabilidade. Guarde a chave em segredo: quem tiver a chave age em seu nome. Você pode apagá-la a qualquer momento com DELETE /api-keys/me, e o administrador pode desativar chaves usadas de forma indevida.

4. Dados cadastrados

  • São públicos. Tudo o que for cadastrado no catálogo pode ser lido por qualquer pessoa, e alterado ou excluído por qualquer pessoa que tenha uma chave de API.
  • São temporários. Os dados, inclusive as chaves de API, ficam num banco em memória e são apagados sempre que o servidor reinicia. Não existe backup.
  • Imagens não são hospedadas. O campo imageUrl das capas guarda só o endereço da imagem. Use apenas links de imagens que você tem direito de divulgar.

5. Disponibilidade e versões

A API é oferecida sem garantia de disponibilidade. Ela pode ficar fora do ar ou demorar para responder.

A versão é escolhida pelo cabeçalho X-API-Version (sem ele, a API responde a versão 1). Mudanças que quebram a compatibilidade saem numa versão nova, e a anterior continua disponível. Cada versão tem a sua documentação no Swagger.
